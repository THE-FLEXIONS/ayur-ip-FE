# Sections

This folder contains reusable visual sections and shared UI pieces used by the page-level components.

Suggested ownership:

- `BrandMark.tsx`: shared Ayur IP brand mark.
- `home/`: home page sections such as the hero, feature overview, workflow, and footer.
- `shared/`: sections reused by more than one page.

Keep route-level composition in `src/pages` and keep reusable visual blocks here.
